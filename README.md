# ScrollHub 1.2
تطبيق أندرويد واحد لتصفح: فيسبوك، تويتر (X)، إنستغرام، يوتيوب، ثريدز.

## الميزات
- شريط أقسام ثابت أعلى الشاشة يحل محل شريط الموقع الأصلي (الأصلي مخفي افتراضيًا في فيسبوك، ويمكن إخفاؤه/إظهاره لكل منصة من القائمة).
- مشغّل وسائط خاص: الضغط على صورة/فيديو يفتحه في مشغّل التطبيق مع أزرار حفظ (الوسائط/الصوت m4a) وزر "ويب".
  - منشور فيه عدة وسائط: تمرير جانبي بينها.
  - الريلز: تمرير عمودي، والرجوع يعيدك إلى نفس الريل في مشغّل الموقع.
- الرسائل وجميع الأقسام متاحة.
- "حفظ" لنسخة المنشور بدون إنترنت + "المحفوظات".
- "التشغيل في الخلفية" لاستمرار الصوت عند الخروج.

## الرفع إلى GitHub من الحاسوب
```
cd ScrollHub
git init
git add .
git commit -m "ScrollHub"
git branch -M main
git remote add origin https://github.com/USERNAME/ScrollHub.git
git push -u origin main
```
ثم: تبويب Actions ← Build APK ← بعد النجاح حمّل ScrollHub-debug-apk من Artifacts (داخله ملف app-debug.apk).

## تعديل سلوك المواقع
كل منطق التعرف على المنشورات وإخفاء الشريط الأصلي في الملف:
`app/src/main/assets/scrollhub.js` وقوائم الروابط في `MainActivity.kt` (حقل navHrefs).
